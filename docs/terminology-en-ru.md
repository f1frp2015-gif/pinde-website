# PINDÉ English–Russian window and door terminology

This glossary is the editorial baseline for `pindesys.com`. English follows the
general terminology used by EN 12519 and ISO 10077. Russian follows the terms
used in ГОСТ 23166-2024, ГОСТ 21519-2022, ГОСТ 30777-2023 and ГОСТ 23747-2015.
The glossary is written for professional fabricators, façade contractors,
importers and project engineers in Central Asia and other Russian-speaking
markets.

The glossary controls wording, not legal conformity. The importer or local
conformity body must confirm which national adoption, EAEU technical regulation
or project specification applies in Kazakhstan, Uzbekistan, Kyrgyzstan,
Tajikistan, Turkmenistan, Armenia, Belarus or Russia.

## Product and component terms

| English | Russian | Editorial note |
| --- | --- | --- |
| window unit / window | оконный блок / окно | Use `оконный блок` in specifications and compliance copy; `окно` is acceptable in headings and plain-language copy. |
| door set / door | дверной блок / дверь | Use `дверной блок` when discussing a tested or supplied assembly. |
| frame | коробка | Use `рама` only where the source document or certificate uses it as a named value such as `Uf рамы`. |
| frame profile | профиль коробки | Do not translate every occurrence of `frame` as `рама`. |
| sash | створка | Use for an operable window element. |
| door leaf | дверное полотно | Use `створка` for sliding glazed leaves only when that is the established system wording. |
| mullion / transom | импост | Add `вертикальный` or `горизонтальный` where the distinction matters. |
| mullionless meeting stile | штульповый притвор | Avoid literal translations such as `non-interlocking`. |
| glazing rebate | фальц остекления | Use for the profile recess that receives glazing and setting blocks. |
| insulating glass unit (IGU) | стеклопакет | Introduce `IGU` once on English technical pages, then use `insulating glass unit`. |
| double-glazed IGU | однокамерный стеклопакет | Two panes form one chamber. Do not write `двойной стеклопакет`. |
| triple-glazed IGU | двухкамерный стеклопакет | Three panes form two chambers. Do not write `тройной стеклопакет`. |
| frame depth / system depth | монтажная глубина | For the depth of the frame/profile system. Do not call an unverified catalogue interface dimension `glazing thickness`. |
| infill thickness | толщина заполнения | Use only where the source clearly refers to glazing or a solid panel. |
| thermally broken aluminium profile | комбинированный алюминиевый профиль с термоизоляционной вставкой | In concise copy, `алюминиевый профиль с термовставкой` is acceptable. `Тёплый алюминий` may appear as a market search term, not as the primary technical term. |
| polyamide thermal barrier / thermal break | термоизоляционная вставка из полиамида | Identify PA66GF25 where the material is confirmed. |
| gasket | уплотнительная прокладка / уплотнитель | Use `уплотнитель` in buyer-facing copy and the longer form in formal specifications. |
| hardware | оконная/дверная фурнитура | Use `комплект фурнитуры` for a system BOM. |
| installation joint | монтажный шов | Distinguish the installation joint from joints inside the frame or sash. |

## Voice rules

- Write for a fabricator checking whether a system can enter production, not for
  a retail homeowner browsing lifestyle claims.
- Lead with the construction, opening type, supply scope or verified result.
- Attribute every test value to its specimen, certificate, catalogue or project
  configuration. A profile depth alone does not prove whole-window performance.
- Prefer a short concrete sentence to adjective chains such as `premium`,
  `innovative`, `superior`, `outstanding` or their Russian equivalents.
- Do not describe a product as `ideal`, `perfect` or `the best choice`.
- Keep English and Russian technically equivalent; they do not need to mirror
  each other word for word.
